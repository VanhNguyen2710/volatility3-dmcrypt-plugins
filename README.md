# Volatility3 Linux Plugins

Custom Volatility3 Linux helper plugins for CTF and memory forensics workflows.

## Plugins

- `linux.bdevinodes`
- `linux.dmcryptprobe`
- `linux.cryptconfigdump`
- `linux.keyringdump`

These plugins are intended to help with Linux block-device, device-mapper, dm-crypt, and kernel keyring analysis.

They are custom/helper plugins, not official upstream Volatility3 plugins.
